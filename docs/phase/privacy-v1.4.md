## 0. 요약

- **바뀌는 곳은 1항 나(수집 항목)와 3항 Anthropic 이전 항목이다.** 덧붙여 2항·3항 이용 목적 말 보충(추천)과 10항 시행일·개정 이력이 바뀐다.
- **새로 AI 로 가는 것(3a 질문 답하기·AI 지도 편집):**
  - 모임·장소 묶음 이름
  - 직접 만든 분류(사용자 카테고리)·그 안의 묶음·항목의 이름과 항목 글
  - 인물 글
  - 기록 사이의 연결
  - AI 에게 하신 기록 정리 요청과 질문
  - 이미 보내고 있지만 목록에 이름이 없던 "인생 시기 이름·연도"도 이번에 적는다.
- **보내지 않는 것은 넣지 않았다:** 인물 메모(`Person.memo`)·출생연도·만난 해·관계 분류, 장소 주소·좌표, 사진·사진 설명, 모임·장소 묶음 메모, 가족 룸 반응.
  - custom-graph §5 표의 "인물에 대해 적은 글·메모" 중 **메모는 뺐다** — 설계된 도구가 읽는 칸(`getMyLifeData`·`NodeBody.plainText`·`Episode.content`)에 메모가 없다(§1.2).
- **⚠️ 3a·AI 지도 편집은 아직 코드가 없다**(origin/main `eb5d6b3` 에 `MAP_ASK`·`find_nodes` 0건). 그래서 "보내는 항목"은 설계가 부르기로 한 데이터 함수의 칸으로 정했고, 3a 구현 때 이 목록을 넘지 않도록 **보내는 칸 계약 + 회귀**를 둔다(§1.3, Q137).
- **이용 목적(§3):** 지도 정리는 "인생 기록 정리", 질문 답하기는 "AI 회상 보조" 안이다. 동의 화면 문구도 Anthropic 용도를 "AI 대화·기록 정리"로 적는다. 새 목적을 만들지 않고, 괄호로 "포함"을 밝히는 보충을 추천한다.
- **동의 버전(§4):** 이전받는 자·국가·목적·보유 기간이 그대로이고 동의 문구도 바뀌지 않는다 → **4 유지**(v1.2 와 같은 판단).
- **공지(§5):** 띠 요약 후보 3개(추천 "AI 전달 정보 추가", 11자). 공지일 = 등록 배포일, 시행일 = 공지일 + 7일(예: 11-06 공지 → 11-13 시행).
- **함께 발견한 것:**
  1. 1항 지금 문장이 이미 실제 수집과 다르다 — 인물 관계 분류·만난 해·메모, 장소 주소, 물건 기록. 같은 개정에서 맞추는 안을 함께 적었다(§2.1 B, Q129).
  2. 오늘의 인터뷰 "관계별 나" 문항에 모임 이름이 AI 로 가는 길이 코드에 있다. 다만 그 조건(시기↔모임 연결)이 운영 0행이고 앱 화면에 그 연결을 만드는 길이 없어 지금은 잠겨 있다(§1.4).
- **본문 표기 정리(§6):** 처리방침 본문에서 규칙에 걸리는 곳은 2줄 3군데다(구글 로그인 줄의 "구글" 2번 · "라이프북의 핵심 기능" 1번). "크롬" 1군데는 판단이 필요하다. 이번 개정에 넣는 것을 추천하고, 약관(표기 1군데 + 조사 오류 2군데 — "라이프북가")은 약관 개정 때로 미룬다.

**v1.2 선례 다섯 가지에 맞춘 판단:**
1. 받는 자·나라·목적·기간이 그대로다 — 동의받은 이전의 범위(누구에게·어디로·왜) 안이다.
2. 더하는 항목은 모두 회원님이 직접 남긴 인생 기록의 일부다(모임·묶음·분류 이름, 인물·항목 글, 기록 사이의 연결, 직접 하신 요청). 같은 목적에 쓴다.
3. 일부는 이미 이전되던 것을 명확히 적을 뿐이다 — 시기 이름·연도는 제안 카드, 대화에서 말한 모임은 "대화 내용".
4. 민감정보를 새로 모으거나 유도하지 않는다. 1항 민감정보 문장("프로파일링이나 광고에 사용하지 않습니다")과도 맞는다 — 지도 도구는 정리·인용만 하고 판정하지 않는다.
5. 동의 문구가 항목을 열거하지 않고 3항으로 넘기므로 동의받은 문구 자체가 바뀌지 않는다.

→ **동의 버전 4 유지, 처리방침 개정·공지로 안내.**

**공지 전 확인할 것:**
- Anthropic 상업 API 의 보유·학습 정책이 처리방침 기재("7일 이내 자동 삭제·학습 미사용")와 여전히 같은지 공지 직전에 확인한다(업체 정책 페이지). 다르면 보유 기간 칸이 바뀌므로 이 판단을 다시 한다.
- 개인정보 보호법 국외 이전 고지 항목(이전 항목·국가·일시·방법·받는 자·목적·보유 기간·거부 방법과 효과)이 3항에 다 있는지 — 지금 다 있음(이전 일시·방법 줄 포함), 바뀌는 것은 항목 칸뿐이다.
- 변호사 검토 목록에 "항목 추가를 재동의 없이 공지로 안내"(v1.2·v1.4)를 올린다.
