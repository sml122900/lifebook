- 상태: **구현 2026-11-08**(§8 — 첫 진입 카드 · 연습 판 3단계 + 끝 · [찾기] 가리키기 · 다시 보기 2곳 · AI 시트 첫 안내). 설계 2026-11-07. 결정 2026-11-08(성민): **T1~T6·T8 = 추천안 확정** · **T7 = (나)안 확정**(조작 안내는 시기·이야기·사람·장소, 첫 카드에만 분위기 한 줄) · 문구는 전부 [임시](도그푸딩 직전 한꺼번에 확정) · 연습 판은 실제 지도와 같은 그리기 코드, DB 쓰기·모델 호출 0 · 구현은 custom-graph 3c 2단계 통과 뒤 시작.
- 이 문서는 `docs/phase/ui-space.md` §6.3(U6 튜토리얼 — Q124 연습 판 · Q125 3a 뒤)을 이어받아 넓힌다. 그 뒤 생긴 것: AI 시트의 [물어보기]·[지도 고치기](custom-graph 3a·3b·3c), 사용자 카테고리, 공전·끌어 넣기·꾸미기, 밤 우주.

## 1. 목표

**성민 의도:** 튜토리얼 몇 번이면 "인생을 지도처럼 만드는 거고, 모르는 건 AI한테 물어보면 되겠네"를 알게 된다.

이걸 확인할 수 있는 말로 바꾸면 튜토리얼을 마친 사람이 다음 셋을 안다.

| # | 알게 되는 것 | 확인하는 방법(도그푸딩) |
|---|---|---|
| G1 | 지도에 무엇이 있는지 — 시기·이야기가 큰 동그라미, 그 둘레에 사람·장소 | 튜토리얼 뒤 첫 행동이 지도 노드 누르기인 비율 |
| G2 | 내가 직접 넣을 수 있다 — 끌어 넣기(또는 버튼) | 튜토리얼 뒤 7일 안에 처음 넣기를 한 계정 비율 |
| G3 | 막히면 AI에게 말로 부탁하면 된다 — 물어보기·고치기, 고치기 전에 먼저 보여 줌 | 튜토리얼 뒤 7일 안에 AI 시트를 연 계정 비율 · 다시 보기 횟수 |

- 지금은 위 비율을 모으는 장치가 없다. `completedTours`(마친 투어 id)만 있다. 측정 방법은 T8 에서 정한다.
- "몇 번이면"은 **처음 한 번 + 필요한 순간 짧은 안내**로 읽었다(T2). 한 번에 다 외우게 하지 않는다.

## 2. 지금 있는 것(코드 기준 사실)

- **엔진** `app/components/CoachMarks.tsx`·`ScreenTour.tsx` + `lib/tours.ts`(단계 = 데이터, 화면 = `data-tour`).
  - 설명형만 된다: 말풍선 [다음]·[건너뛰기]. 가리킨 곳을 직접 눌러서 다음으로 가는 기능은 없다.
  - 첫 방문 1회 자동(`User.completedTours`, 마이그 0) + 떠 있는 [도움말] 버튼으로 다시 보기 + `START_TOUR_EVENT`.
  - 지금 투어: 옛 연혁 화면(main) · 포스터 3화면 · 말동무. **My Life 투어는 없다**(`app/my-life` 의 `data-tour` 2곳뿐).
- **첫 진입 흐름(V3):** `/enter` → `/start`(인트로 한 화면) → `/chat-v3`(신상·골격 확인 → 자유 대화) → 골격 확인이 끝나면 `/my-life`.
  - 그래서 **My Life 첫 화면은 거의 빈 지도**다. 기본 시기(출생·학교 등) 몇 개와, 대화에서 만든 이야기 0~2개뿐이고 사람·장소 위성은 보통 없다.
- **이미 정한 것(ui-space §6.3):** ① 행성 누르기 = 설명형 · ② 끌어 넣기 = **연습 판**(가짜 행성·가짜 위성, DB 쓰기 0 — Q124) · ③ AI = 3a 배포 뒤(Q125 — 이제 조건 충족).
- **화면 조건:** 밤 우주(단일 테마) · 공전 움직임(reduced-motion·[움직임 멈추기]면 멈춤) · 390 첫 화면 지도 상자 약 530px · `/my-life` 첫 진입은 사이드 패널 닫힘 · 글자 18px 이상·누르는 곳 48~56px.
- **AI 비용:** 질문 1회 약 $0.004 · 고치기 1회 약 $0.007, 사용자당 하루 30회 한도(질문·고치기 합산).

## 3. 제약

- 한 번에 하나, 쉬운 말, 단계 짧게(시니어 접근성). 단계 하나의 글은 60자 안팎.
- 튜토리얼이 **실제 지도·기록을 바꾸지 않는다.** 연습은 DB 쓰기 0.
- 튜토리얼이 **유료 모델을 부르지 않는다**(T6 에서 다른 안을 고르지 않는 한).
- 연습 판의 가짜 이름은 테스트 픽스처·재생 세트·실제 대화와 무관한 소재로 쓴다(작업 규칙 8 의 취지).
- 페이지 이동을 새로 만들지 않는다 — 시트·말풍선 안에서 끝난다(작업 규칙 7 대상이 생기면 그때 갱신).
- 움직임: reduced-motion 이면 나선·출렁임 없이 결과만. 공전 중인 지도 위에 말풍선을 붙이면 흔들린다.

## 4. 결정 질문

### T1. 언제 시작하나(첫 진입 흐름)

| 안 | 내용 | 장점 | 걸리는 점 |
|---|---|---|---|
| A | `/my-life` 첫 진입 때 바로 자동 시작(지금 엔진 방식) | 놓치는 사람 없음 | 대화를 막 끝내고 온 사람 화면을 갑자기 덮는다. 시니어에게 "뭐가 덮었지" 혼란 |
| **B(추천)** | 첫 진입 때 지도 위 작은 카드 한 장: "1분이면 지도 쓰는 법을 볼 수 있어요" [둘러보기]·[나중에] | 본인이 시작을 고름. [나중에]면 다시 보기 자리를 알려 주고 닫음 | 한 번 더 눌러야 함. [나중에]만 누르고 영영 안 볼 수 있음 |
| C | `/chat-v3` 마무리 화면에서 "지도로 가기 전에 둘러볼까요?" | 흐름이 자연스러움 | 대화 화면 수정 필요 · 지도를 보기 전에 지도 설명을 듣게 됨 |

- 추천 B: 덮지 않고 묻는다. [나중에]를 누르면 카드는 다시 안 뜨고(완료 표시와 같은 칸에 `my-life-later` 같은 id), 다시 보기 자리(T3)를 한 줄로 알려 준다.

### T2. 몇 단계, 한 번에 아니면 나눠서

| 안 | 구성 | 장점 | 걸리는 점 |
|---|---|---|---|
| A | 한 번에 5단계(행성·위성 / 넣기 / 물어보기 / 고치기 / 다시 보기) | 다 알려 줌 | 길다. 시니어는 3단계 넘으면 앞을 잊음 |
| **B(추천)** | **한 번에 3단계 + 필요한 순간 짧은 안내 1개** · ① 지도 읽기 ② 직접 넣어 보기 ③ 막히면 AI에게 — 끝 카드 1장. 그리고 AI 시트를 처음 열 때 [물어보기]·[지도 고치기] 차이 한 줄 | 목표 세 줄(G1~G3)과 1:1. 1분 안 | 안내가 두 곳에 나뉨 |
| C | 나눠서: 첫 진입 = ①·③, 처음 사람·장소가 생겼을 때 = ② | 필요할 때 배움 | ②가 영영 안 뜰 수 있음(사람·장소를 안 만들면). 상태가 늘어남 |

### T3. 건너뛰기·다시 보기

| 안 | 건너뛰기 | 다시 보기 | 걸리는 점 |
|---|---|---|---|
| A | 단계마다 [건너뛰기](지금 엔진) — 누르면 완료로 침 | 지도 위 떠 있는 [도움말] 버튼(포스터 화면과 같은 방식) | 지도 위에 떠 있는 버튼이 이미 많다(AI 비서·[내 정보]·확대 줄). 하나 더 늘면 지도가 좁아짐 |
| **B(추천)** | A와 같음(완료로 침 — 다시 자동으로 안 뜸) | [내 정보] 사이드 패널 "도움" 묶음에 "지도 쓰는 법 다시 보기" 한 줄 + [찾기] 시트 맨 아래 같은 링크 | 지도 화면은 그대로. 찾는 데 한 번 더 눌러야 함 |
| C | 건너뛰면 다음 방문에 한 번 더 물음(최대 1회) | B와 같음 | 상태가 하나 더 늘어남 |

### T4. 우주 화면 위에서 어떻게 보여 주나

| 안 | 내용 | 장점 | 걸리는 점 |
|---|---|---|---|
| A | 실제 지도 위 설명형(지금 엔진의 어두운 덮개 + 구멍) · 튜토리얼 동안 공전 멈춤 | 자기 지도를 보면서 배움 | 첫 진입 지도는 거의 비어 **보여 줄 위성이 없다.** 어두운 덮개가 밤 우주 위에서 대비가 약함 |
| **B(추천)** | **연습 판**(시트 안 작은 가짜 지도 — 행성 1개 + 위성 2개 + 넣을 것 1개)에서 ①·②, 실제 화면에서는 ③만 [찾기] → [AI에게 부탁하기] 자리를 가리킴 | 빈 지도여도 똑같이 보여 줌 · 실제 지도·기록 무변 · 공전·꾸미기를 그대로 보여 줌 | 연습 판 화면을 새로 만들어야 함(실제 행성·위성 그리기 코드를 재사용) |
| C | 전부 연습 판(AI도 연습 판 안에서) | 한 화면에서 끝 | 실제 AI 버튼이 어디 있는지는 모르고 끝남 |

- B의 연습 판은 실제 지도와 같은 그리기 코드·같은 밤 우주 색을 쓴다(다른 그림이면 "이건 내 지도와 다르네"가 됨). 가짜 데이터는 순수 모듈 한 곳.
- 공전: 연습 판은 처음엔 돌고, 행성을 누르면 멈추고 펼친다(실제와 같음). reduced-motion 이면 처음부터 멈춤.

### T5. 끌어 넣기 체험(②)

| 안 | 내용 | 걸리는 점 |
|---|---|---|
| **A(추천 — Q124 결정 그대로)** | 연습 판에서 가짜 위성을 가짜 행성에 끌어 넣기. 한 번 성공하면 "잘하셨어요" + 버튼으로 넣는 길도 한 줄. 두 번 실패하면 버튼 넣기로 바꿔 보여 줌 | 실제 넣기와 손맛이 같아야 함 — 실제 끌기 코드(`lib/space-drag.ts`·`app/my-life/drag.ts`) 재사용, 저장만 안 함 |
| B | 실제 지도에서 실제 사람을 넣어 보기(되돌리기 안내) | 첫 진입엔 넣을 사람·장소가 보통 없음. 기록이 남음 |

### T6. [물어보기]·[지도 고치기] 체험(③)

| 안 | 내용 | 비용·기록 | 걸리는 점 |
|---|---|---|---|
| A | 설명형만 — AI 버튼 자리를 가리키고 예시 문장 두 개("부모님 이야기는 몇 개야?" · "○○를 가족에 넣어 줘" — 예시 이름은 픽스처와 무관하게) | 0 · 0 | 직접 해 보지는 않음 |
| **B(추천)** | 연습 판 안 **미리 써 둔 체험**: 예시 버튼을 누르면 실제 화면과 같은 카드가 나옴 — 물어보기 = 답 + 근거 칩, 고치기 = 확인 카드 → [이대로 하기] → 결과 카드 → [되돌리기]까지. "연습이에요" 꼬리표 | 0 · 0 | 진짜 모델 답이 아님(예시가 실제보다 매끄러워 보일 수 있음 — 실제 카드와 같은 부품·같은 말투로 맞춤). 끝에 실제 버튼 자리를 가리킴 |
| C | 실제 시트를 열고 예시 문장을 채워 둠 → 누르면 실제 모델 호출 | 질문 1회 약 $0.004(하루 30회 한도에서 1회) · 원장 1행 | 첫 진입 지도는 거의 비어 "지도에 아직 없는 이야기예요"가 나오기 쉬움 — 첫인상이 나쁨 |

- 추천 B의 핵심은 "고치기 전에 먼저 보여 주고, 되돌릴 수 있다"를 몸으로 아는 것이다. 지우기·합치기는 연습에 넣지 않는다(되돌릴 수 없는 일을 연습시키지 않음).

### T7. "행성·위성"이라는 말을 쓰나(ui-space Q128 미결)

> **결정(2026-11-08 성민 — (나)안):** 조작 안내에는 "행성·위성"을 쓰지 않고 **시기·이야기·사람·장소**로 부른다. **첫 카드에만 분위기 문장 한 줄**을 허용한다(방향: 기억을 밤하늘의 별처럼 띄워 두는 지도). 그 문장은 [임시]로 넣고 도그푸딩 직전 문구 확정 때 성민이 정한다. 아래 표의 A·B 는 결정 전 안이다.

| 안 | 내용 | 걸리는 점 |
|---|---|---|
| **A(추천)** | 튜토리얼 말은 **시기·이야기·사람·장소**로만. 모양은 "큰 동그라미 둘레를 작은 동그라미가 돌아요" 정도로 그림이 대신 | 화면 문구 2곳("위 행성으로"·"행성에 붙어요")과 말이 다름 — 같이 고칠지 따로 정함 |
| B | 한 번 풀어 줌: "이야기는 행성, 그 이야기에 나온 사람·장소는 위성이에요" | 비유를 하나 더 외워야 함(문구 판단 기준 — 성인 누구나 바로 알아듣는 말) |

## 5. 추천안 묶음(위 표의 추천만 모은 흐름)

```
/my-life 첫 진입
  └ 카드 [분위기 한 줄 — 임시: 기억을 밤하늘의 별처럼 띄워 두는 지도] "1분이면 지도 쓰는 법을 볼 수 있어요" [둘러보기] [나중에]   ← T1 B · T7 (나)
       [나중에] → "다시 보기는 [내 정보] › 도움에 있어요" 한 줄 뒤 닫힘       ← T3 B
       [둘러보기] → 연습 판(시트) 열림                                          ← T4 B
          ① 지도 읽기: 가짜 행성 하나가 돌고 있음 → 누르면 멈추고 펼침
             "큰 동그라미는 시기와 이야기, 둘레의 작은 동그라미는 거기 나온 사람과 장소예요"   ← T7 A
          ② 직접 넣기: 가짜 사람 하나를 꾹 눌러 행성으로 → 나선·출렁 → "잘하셨어요"
             두 번 실패하면 [버튼으로 넣기]                                       ← T5 A
          ③ AI에게: 예시 [부모님 이야기는 몇 개야?] → 답 카드 / [○○를 가족에 넣어 줘] → 확인 카드 → 결과 → [되돌리기]   ← T6 B
```
