# 토큰 충전 — 토스 심사(포인트충전 업종) 준비 (2026-11-10)

토스가 Lifebook 을 **포인트충전 업종**으로 분류 → 이번 심사에 토큰 충전도 포함(성민 지시 2026-11-10). 카드사 심사는 아직 시작 전.
문구는 전부 [임시 — 성민 확정 필요] · [법률 검토 필요].

## 1. 상품(서버 진실 = `lib/tokens/policy.ts` `TOPUP_PACKAGES`)

| id | 결제 금액 | 받는 토큰 | 그중 더 드리는 토큰 |
|---|---|---|---|
| starter | 1,000원 | 100 | 0 |
| value | 3,000원 | 330 | 30 |
| popular | 5,000원 | 575 | 75 |
| max | 10,000원 | 1,250 | 250 |

기준 1,000원 = 100토큰. 무료 지급: 가입 50(`signup_grant`) · 출석 매일 5(`daily_attendance`) · 7일 연속마다 +30(`attendance_streak_bonus`). 차감을 되돌린 것(`*_refund` — 검색 실패 등)은 꺼낸 칸으로 돌아감.

토스 공개 안내(카드사 심사 체크리스트, 2026-10-06): 충전 서비스는 **1일 최대 결제 금액 5만 원 미만**(카드사 정책). 한 번 최대 10,000원이라 한 건은 문제없고, 하루 여러 번이면 카드사 한도가 걸림 — 우리 서버의 하루 한도는 없음(필요하면 추가).

## 2. 경로

- 상품 소개(로그인 없이): 상점 `/shop` [토큰 충전] → `/shop/tokens`(금액·토큰·환불과 쓰는 곳) → [충전하러 가기]
- 충전(로그인): `/billing` — 충전할 토큰 고르기 → 토스 결제위젯 v2(인쇄본과 같은 위젯 키 — 결제 수단·약관) → [N원 충전하기] → 결제창 → `/billing/success`(서버가 위젯 시크릿 키로 승인 + 주문 금액과 대조 → 즉시 적립)
- 다른 입구: [내 정보] → [상품 구매] → 상점 · [내 정보] → 토큰 화면 → [토큰 충전하러 가기] · 토큰이 부족할 때 안내

## 3. 환불(문장 한 곳 = `lib/commerce/order-display.ts` `TOKEN_REFUND_LINES`)

같은 문장: 환불정책 `/refund` 토큰 충전 절(v1.2) · 이용약관 제25조(v1.2) · 충전 화면 · 상점 토큰 상세 · 고객센터 "토큰 환불이 되나요?". 옛 "충전한 토큰은 환불이 어렵습니다" 지움.

- 결제 후 7일 안 + 하나도 안 쓴 충전 = 결제 금액 전부
- 그 밖 = 결제 금액 × 남은 토큰 ÷ 그 충전으로 받은 토큰(더 드린 토큰 포함), 원 아래 버림
- 무료 토큰은 환불 대상 아님 · 사용 순서 = 무료 먼저 → 먼저 충전한 것부터
- 쓰는 곳 = Lifebook 서비스 한 곳, 현금·다른 서비스로 바꿀 수 없음
- 고객센터 요청 → 3영업일 안 결제 수단으로

**계산이 되는지**: 지갑은 잔액 한 칸이지만 모든 잔액 변경이 원장(`TokenTransaction`)에 이유와 함께 남음(`lib/tokens/wallet` 불변식). `lib/tokens/refund.ts` `quoteTopupRefunds` 가 원장을 처음부터 따라가 무료·충전 건별 남은 토큰을 셈. 운영 32지갑 전부 무료 + 유료 남은 = 잔액(2026-11-10 `db/token-refund-quote.ts --all`, 읽기만). 건별 금액 = `--email <이메일>`.

**아직 없는 것**: 환불 실행(토스 결제 취소 + 원장 차감). 실결제를 켜기 전에 만든다.

## 4. 토스 질문 답안 초안

| 질문 | 답 |
|---|---|
| 용도 | Lifebook 회원이 AI 기능(AI에게 그 시절 물어보기(인터넷 검색), 글 다듬기, 말동무 대화 등)을 쓸 때 쓴 만큼 차감되는 서비스 이용 포인트(토큰). 1,000원 = 100토큰(3,000원 이상은 토큰을 더 드림). 가입·출석 때 무료 토큰도 드림. |
| 사용 경로 | 충전: 상점(`/shop`) → 토큰 충전(`/shop/tokens`, 로그인 없이 금액·환불 확인) → [충전하러 가기] → 로그인 → 충전 화면(`/billing`)에서 금액 선택 → 토스 결제위젯 → 결제창 → 결제 즉시 적립. 사용: 로그인 뒤 AI 기능을 쓰면 자동 차감, 잔액·내역은 [내 정보] → 토큰 화면. |
| 환불 정책 | 결제 후 7일 안에 하나도 쓰지 않은 충전은 전액 환불. 일부 썼거나 7일이 지나면 남은 유료 토큰만큼(결제 금액 × 남은 토큰 ÷ 받은 토큰) 환불. 무료 지급 토큰은 환불 대상 아님, 사용은 무료 → 유료 순. 고객센터 요청 → 3영업일 안 결제 수단으로. 게시: 환불정책·이용약관 제25조·충전 화면·상품 화면·고객센터. |
| 사용처 1곳 | Lifebook 서비스(https://lifebook-mauve.vercel.app) 안에서만 사용. 다른 가맹점·서비스에서 쓸 수 없고 현금으로 바꿀 수 없음. 회원끼리 주고받는 기능 없음. |
