# Lifebook 비전

## 장기 비전

**나보다 나를 더 잘 아는 에이전트.**

## 출발점

외할머니 인터뷰 → 인생 연혁 → A2 인생 포스터 실물.

## 최종 목표

1. 사용자가 서비스 채팅으로 인생 전체를 회고한다.
2. 그 기록을 학습한 에이전트를 사용한다.
3. 실사용자를 확보한다.

## 원칙

- 인생 기록 데이터는 외부 제공·광고 활용 금지.
- 에이전트 답변은 원문 인용 필수 — 근거 없는 주장 금지.

## 알려진 위험

- **수익모델 공백** — 자기 모델은 지속 비용이 드는데, 포스터는 1회 판매다.
- **타깃 이중화** — 20대의 자기탐색 vs 어르신의 포스터.
- **인물 그래프 = 타인 개인정보.**
- **도그푸딩 N=1 편향.**
