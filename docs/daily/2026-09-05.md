# 2026-09-05 — v3 P13 긴급 (Chrome prod test20: 딥링크 진입 후 세션 고착)

## 근본 원인 (P13-1·P13-2 공통)

P12-6 에서 딥링크 소비 직후 `window.history.replaceState(null, "", "/chat-v3")` 로 주소만 정리하려 한 것이 원인. Next 16.2.6 앱 라우터는 `replaceState` 를 패치해 `ACTION_RESTORE` 를 dispatch 하고(`app-router.js` `applyUrlFromHistoryPushReplace`), `restoreReducer` 가 세그먼트 캐시로 `startPPRNavigation` + `spawnDynamicRequests` 를 돌린다. 페이지 세그먼트 키에 searchParams 가 포함되므로(`__PAGE__?{gapEventId…}` → `__PAGE__`) 페이지 서브트리가 **리마운트**됐다 — 새 인스턴스는 `initialGap=null` 로 init 을 다시 돌고, 첫 인스턴스의 init 체인은 고아가 된다. test20 DB 로그가 이를 그대로 보여줌: 딥링크 세션마다 안내/오프닝 버블이 0건, 한 세션은 stage 초기값(`profile_year`)의 "태어나신 연도" 폴백으로 응답. 주소 변경이 없는 open 모드만 정상이던 이유. 사용자가 본 `{"f":"","q":"","i":false}` 는 이 restore 가 띄운 RSC 요청 응답. "소프트 종료"는 무관한 선행 조건이었다(서버에 closed 상태 없음).

## 픽스

- **P13-1** — `replaceState` 제거. 대신 stale 딥링크 표식: 채팅 안 갭 칩 클릭 시 `sessionStorage["chat-v3:deep-link-consumed"]=<eventId:kind:personId>`, init 은 같은 키의 initialGap 을 무시(pending/자연 분기). 클라이언트 라우팅 언마운트 시 표식 제거(같은 카드 재클릭은 새 의도), 새로고침은 언마운트를 안 타 표식 유지. 주소는 절대 건드리지 않는다.
- **P13-2** — pending 과 다른 딥링크는 원래 코드도 딥링크 우선이었으나(P9-2 는 "같을 때"만 resume) 리마운트 증상으로 겹쳐 보임. 명시적으로 `if (pending) clearPending()` 을 start* 앞에 추가(옛 컨텍스트 잔존 0).
- **P13-3** — `withTimeout`(45s) 로 서버 액션 9곳 래핑 → 초과 시 catch → `enterError`(다시 시도). 빈 응답 폴백 `"잠시 문제가 있었어요. 다시 말씀해주세요."`(episode·open). `finishSession` 은 `setStatus("finished")` 를 addBot await *앞*에 두어 전환 중 입력 창구 제거.
- **후속 결함(발견)** — 종료 직후 재진입 시 P9-3/P3-6 dedupe 가 "마지막 메시지가 봇 발화" 만 보고 확인질문/인사를 안 붙여 입력창만 남았다. `SESSION_END_MESSAGES` + `endsWithPendingBotTurn()` 으로 마무리 문구는 "대기 중 질문"에서 제외(3곳 통일).

## P13-4 open 모드 저장 없음 — 조사·제안

- 현황: `respondToOpenChat` 은 단일 턴 `chat()` 호출뿐 — 히스토리·요약·저장·인물 추출 전부 없음(설계 의도: "짧게 듣고 반응만"). 사용자가 여기서 실질 이야기를 하면 로그(OnboardingChatMessage)에만 남고 Episode/Person 으로는 안 간다.
- 판단: 유실이 맞다. 어르신은 "하고 싶은 이야기 있으세요?" 에 실제 이야기를 꺼내는 게 자연스럽고, 갭 카드가 3장 미만인 후반부일수록 open 모드 체류가 길어진다.
- 제안(작업 안 함): (a) 최소 — open 턴에서도 이름 있는 인물만 `savePeopleMentionedInEpisode` 와 같은 추출을 돌려 Person 저장(연결 이벤트는 없으니 PersonLifeEvent 없이, 또는 최근 이벤트에 연결). (b) 권장 — open 발화가 "실질 이야기"(길이 ≥ N자 또는 연도·사건 언급)면 episode 엔진으로 승격: `CUSTOM` LifeEvent(제목=요약 1줄) 를 만들고 STAGE4 로 이어가 마무리 시 Episode 저장. (c) 대안 — open 모드 진입 시 "말씀하신 이야기는 따로 저장되지 않아요. 저장하려면 아래 카드를 골라주세요" 안내. 우선순위는 (b) > (a) > (c), 결정 필요.
